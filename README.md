# Full Stack Web Development Journey

Welcome to my learning repository! Here, I document my daily progress across Frontend, Backend, and AI integrations. This repo is structured modularly to track every milestone from core web basics to full-stack architectures.

---

## 🚀 Learning Roadmap & Milestones

### 🎨 Frontend
- **HTML & CSS Foundations**: Semantic HTML5, CSS Flexbox, Grid, Animations, Responsive Design.
- **JavaScript Core & Advanced**: Scope, Closures, Prototypes, Asynchronous JS, Promises, Event Loop, DOM Manipulation.
- **React.js**:
  - Components, JSX & Virtual DOM
  - Hooks: `useState`, `useEffect`, `useCallback`, `useRef`, `useContext`
  - React Router DOM & Single Page Application (SPA) routing
  - Context API & Global State Architecture
- **Tailwind CSS**: Modern utility-first responsive styling.

### ⚙️ Backend & Systems
- **Node.js Core**: Modules (`fs`, `path`, `os`, `http`), Event Loop architecture, streams, buffers.
- **Express.js Framework**:
  - RESTful API design & routing
  - Custom & Built-in Middlewares (`express.json`, `express.urlencoded`, `express.static`)
  - Server-Side Rendering (SSR) with EJS
  - File handling & multipart uploads with Multer
- **Database & Modeling**: MongoDB, Mongoose schemas, validation, indexing & MVC patterns.
- **Security & Authentication**:
  - Stateful vs. Stateless Authentication
  - JWT (JSON Web Tokens) & HTTP-only Cookies
  - Password hashing & authorization middlewares
- **AI Integrations**: Google Gemini Generative AI SDK, prompt engineering APIs, streaming chat interfaces.
