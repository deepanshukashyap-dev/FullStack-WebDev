  2. By default direction of flexitems is flex-direction:row , isliye jese hi container ko flex mark karenge items aapne aap row wise arrange ho jaynge.
  3. If flex-direction:column , item inside the flexbox arranged in column wise

Justify-content:

  • If the flex-direction is set to row which is by default already , the main axis will be =>HORIZONTAL Axis
  • If the flex-direction is set to column , the main axis will be =>VERICAL Axis
  1. Justify-content:centre (elements placed at the centre)
  2. Justify-content:start
  3. Justify-content:end
  4. Justify-content:space-between (first and last element in extreme end or baaki ke beech me equal space)
  5. Justify-content:spcace-around (har element ke left and right me equal space)
  6. Justify-content:space-evenly (sabke beech me equal spaces)
