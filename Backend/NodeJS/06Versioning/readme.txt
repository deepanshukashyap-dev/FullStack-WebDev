//Version

^5.2.1

1st part -> 5
2nd part -> .2
3rd part -> .1

//3rd part is for patches and bug fixes(optional)

//2nd part is for backward compatible features , Recommended bug fixes (Recommended)


//1st part is for major changes that break backward compatibility(mandatory)

^ mean compatible with version (1 remain same , 2 and 3 can change)
~ mean approximately equivalent to version (1 and 2 remain same , 3 can change)

//Example : 1.0.0 -> 2.0.0 (breaking changes)
//Example : 1.0.0 -> 1.1.0 (new feature added in backward compatible manner)
//Example : 1.0.0 -> 1.0.1 (bug fixes in backward compatible manner)
