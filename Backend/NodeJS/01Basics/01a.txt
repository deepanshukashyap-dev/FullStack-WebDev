in production there are lots of modules , so we split the code in different files so that all the related functions grouped and can be called on demand to write clear and modular code.
importing maths.js file and storing in variable by storing the imported "file" in a variable we can access its exported "functions"

When you require/import a module in Node.js, the module.exports object is returned.
If the module exports a single function directly (like in maths.js), you can call it directly without storing it in a variable. However, if the module exports multiple members (like functions, objects, etc.), you would typically store it in a variable to access those members
